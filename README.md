git commands

git status : show modified files in working directory, staged for your next commit

git clone : git clone command downloads an existing Git repository from a remote server

git checkout : git checkout command is a versatile Git utility used to switch branches, inspect old commits, and discard local file modifications

git push : git push command uploads your local repository commits to a remote repository

git pull : git pull command is used to download changes from a remote repository and immediately integrate them into your current local branch
